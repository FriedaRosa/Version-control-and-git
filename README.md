# Version Control and Git

A teaching resource introducing version control concepts, Git, and GitHub workflows. This repository contains presentation materials, practical setup instructions, and supporting resources developed using Quarto.

## Overview

This project was created to support training in:

- Principles of version control
- Git installation and configuration
- Local repositories and commit workflows
- Working with remote repositories
- GitHub integration
- Reproducible research practices

The content is provided in both presentation and tutorial formats and can be rendered as HTML or PDF documents.

## Learning Objectives

After working through these materials, participants should be able to:

- Understand why version control is important
- Configure Git on a local machine
- Create and manage repositories
- Track changes using commits
- Connect local repositories to GitHub
- Collaborate effectively using Git workflows
- Apply version control principles to research projects
